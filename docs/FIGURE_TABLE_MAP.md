# Figure and table map

All paths below are relative to the repository root. `python reproduce.py all`
regenerates the records, numerical plotting inputs, tables, and figures in
`build/all/`. `python reproduce.py figures` rebuilds the figures from the supplied records.

|---|---|---|---|
| Figure 1: control architecture | `paper/figures/fig_architecture.tex` | Diagram source; no simulation | `artifacts/figures/figure_1_architecture.pdf` |
| Figure 2: operational risk maps | `calibration()` and `quadrature_risks()` | `operational_risk_table.csv` → `riskmap_low.csv`, `riskmap_med.csv`, `riskmap_high.csv` | `artifacts/figures/figure_2_risk_maps.pdf` |

The additional ablation and shift summaries are exported to
`artifacts/export/tables/`. The full matched-query records retain both successful
and failed comparisons. The EB-only rollout files contain every executed
continuation step.

## Rendering

Figures are compiled with the IEEEtran text dimensions, including its font
settings. Standalone entry points are generated by `scripts/build_assets.py`.
The `preview` package crops the figure page, and three LaTeX passes resolve
shared legends. PDF output is vector-based; PNG previews use 200 dpi.

The right-axis label in Figure 4 has an outward offset and a slightly wider
panel separation to keep it clear of the tick labels. The plotted data and
series remain identical to the manuscript's numerical inputs.

The final eight-page manuscript is supplied only as `paper/manuscript.pdf`.
Its LaTeX source is not part of this reproducibility repository. The figure
sources are retained because they are part of the numerical rendering pipeline.
